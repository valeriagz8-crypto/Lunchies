# Redesign illustration credits

Every file in this folder is a crop of the author's own redesign mockups in
`mockups/redesign/`, cut with a script (Pillow) and re-encoded as WebP.

They are decoration only: each one is rendered with `next/image` and an empty
`alt`, marked `aria-hidden`, and none of them carries text, a logo, a person or
any information that is not already written on the page.

| File | Cropped from | What it shows |
| --- | --- | --- |
| `hero-core.webp` | `core.png` | Green lunchbox: heart sandwich, strawberries, star carrots, cucumber |
| `hero-product.webp` | `product.png` | Pink lunchbox: heart sandwich, pinwheels, celery, star carrots |
| `hero-research.webp` | `research.png` | Green lunchbox: heart sandwich, strawberries, cucumber, star carrots |
| `hero-pricing.webp` | `pricing.png` | Green lunchbox: star sandwiches, cucumber, strawberries, star carrots |
| `docs-notepad.webp` | `docs.png` | Notepad with a pen and three check marks |

The sticky notes beside each hero lunchbox were deliberately excluded from the
crops because they contain text. The Docs folder illustration was excluded for
the same reason: it has "Lunchies" written across the front.

The five weekday lunchbox pictures were cropped and then removed again: placed
on the weekday cards they read as photographs of that day's generated meal,
which is not what they are. The weekday cards keep their pastel tints and the
generated text on its own.
